### 👋 About Me

I'm a **Full-Stack AI Engineer** from **FAST-NUCES Islamabad**, building products that pair clean full-stack engineering with practical AI. I work across the stack — React/Next.js frontends, FastAPI and Node.js backends, PostgreSQL and Redis data layers — and ship them with Docker, Kubernetes, and CI/CD pipelines.

- 🔭 Currently building **CivicPulse**, an AI-powered municipal complaint triage and operations platform
- 🧠 Integrating LLMs (**OpenAI, Claude, Gemini**) into real applications and automating workflows with **n8n**
- ☸️ Deepening my skills in **cloud-native deployment** — Kubernetes autoscaling (HPA/VPA), AWS, and Azure
- 🧩 Strong foundation in **Data Structures, Algorithms, and OOP** across C++, Java, and Python
- 💬 Ask me about FastAPI backends, LLM integration, or containerizing and scaling apps
